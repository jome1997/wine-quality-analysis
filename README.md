# Wine Quality Analysis

## Question
Which chemical properties are most linked to wine quality?

## Data
WineQT dataset: 1,143 wines, 13 columns. No missing values and no duplicates.

## Tools
Python (pandas, matplotlib), Google Colab

## Findings
- Alcohol has the strongest positive link with quality (+0.48). Wines with more alcohol tend to score higher.
- Volatile acidity has the strongest negative link (-0.41). Wines with more of it tend to score lower.
- Most wines scored 5 or 6. Very few scored 3 or 8, so results for those scores are less reliable.
